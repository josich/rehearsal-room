# The Rehearsal Room

A walkable 3D basement rehearsal studio that runs in the browser (three.js). Everything - geometry, materials, sounds - is generated in code.

**Open it:** https://josich.github.io/rehearsal-room/

- Phone: left thumb walks, drag the right side to look, tap drums, cymbals, guitars, amps and lamps.
- Computer: click to look around, WASD to walk, Shift to run, click things to play them.
